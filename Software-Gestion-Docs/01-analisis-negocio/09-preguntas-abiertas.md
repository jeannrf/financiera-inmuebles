# 09. Preguntas abiertas para el cliente

> Hay que enviárselas por escrito (el cliente dijo: "pásame las preguntas por escrito") y cerrarlas antes del SRS.
> Las marcadas con ⭐ bloquean el diseño y conviene resolverlas primero.

## Generales y comerciales

| ID | Pregunta |
|----|----------|
| P01 | ¿Confirmamos la fecha y la hora de la próxima reunión (unos 28 de noviembre de 2026) y el coworking? |
| P02 ⭐ | ¿Nos puede compartir los **Excel actuales** (alquileres y servicios) y ejemplos de vouchers y recibos, aunque sea con datos ocultos? |
| P03 ⭐ | **Propiedad intelectual**: ¿el producto será del equipo (y usted es el primer cliente) o será suyo (con un compromiso de mantenimiento)? |
| P04 ⭐ | ¿Le parece bien una **aplicación web** (se usa desde el navegador de la laptop y del celular) en lugar de un programa instalado en una sola computadora? |
| P05 | ¿Qué nombre le gustaría para el software? |
| P06 | ¿Cuántos inmuebles, departamentos e inquilinos tiene hoy, y cuántos espera tener en 2–3 años? |
| P07 | ¿Cuántos analistas trabajarían al inicio? ¿Ya hay alguno? |

## Inmobiliario: inmuebles, contratos y cobros

| ID | Pregunta |
|----|----------|
| P10 | ¿El valor se registra por **edificio**, por **departamento** o por ambos? Si es por edificio, ¿cómo se reparte el rendimiento entre los departamentos? |
| P11 | ¿Un contrato puede tener **varios inquilinos** (pareja, compañeros)? ¿Quién es el responsable del pago? |
| P12 | ¿Qué medios de pago acepta (Yape, Plin, transferencia, efectivo)? ¿Hay depósito de garantía? ¿Cómo se registra y se devuelve? |
| P13 ⭐ | La alerta al dueño, ¿a los **5** o a los **7** días de atraso? ¿Quiere SMS, correo o ambos? |
| P14 | ¿El saludo de cumpleaños se envía por correo? ¿Con algún texto o diseño en particular? |
| P15 | ¿Se puede cerrar un mes si un inquilino quedó como **incobrable**? ¿Se puede **reabrir** un mes cerrado? |
| P24 ⭐ | ¿Se aceptan **pagos parciales**? ¿Se cobra **mora o penalidad** por atraso? |
| P28 | ¿El día de pago es el mismo para todos o depende de cada contrato? |
| P29 | ¿Qué hacer con el contrato al renovarlo: se crea uno nuevo o se extiende el actual? ¿Con cuántos días de anticipación quiere la alerta? |
