# 09. Glosario de la plataforma

Cada clúster tiene su propio glosario con los términos de su rubro.

| Término | Definición |
|---------|------------|
| **Clúster** | Grupo de tipos de negocio que comparten forma de operar y de ganar dinero. Hay 6. |
| **Vertical** | Tipo específico de negocio dentro de un clúster (por ejemplo, 4.3 Gimnasios). |
| **Núcleo (Core)** | Funcionalidad siempre activa que usan todos los negocios. |
| **Motor** | Funcionalidad reutilizable y activable por clúster (cobro recurrente, agenda, inventario…). |
| **Paquete de clúster** | Código compartido por los negocios de un clúster. |
| **Plantilla de vertical** | Configuración por metadatos que adapta el paquete a un rubro. |
| **Metadatos** | Datos que describen la estructura o comportamiento del software (campos, estados), editables sin programar. |
| **Fábrica de software (oculta)** | Capacidad interna para armar el software de un negocio combinando las piezas anteriores. |
| **Organización** | El cliente de la plataforma; puede tener varios negocios. |
| **Negocio** | Unidad gestionada dentro de una organización, con una vertical activada. |
| **Multi-tenant** | Una sola instalación que sirve a varios clientes con sus datos aislados. |
| **Holding View** | Tablero del dueño con una tarjeta por negocio. |
| **Contacto / Contraparte** | Persona o empresa del directorio. Según la vertical es inquilino, paciente, cliente o proveedor. |
| **Obligación** | Monto que debe pagarse con fecha de vencimiento. Su nombre cambia por vertical: cuota, pensión, factura. |
| **Comprobante de pago** | Evidencia de un pago. No es lo mismo que el **comprobante electrónico** SUNAT (boleta o factura). |
| **Centro de costo** | Elemento al que se imputan ingresos y gastos para medir su rentabilidad. |
| **P&L** | Estado de Resultados: ingresos menos gastos en un período. |
| **CxC / CxP** | Cuentas por cobrar / cuentas por pagar. |
| **RBAC** | Control de acceso basado en roles: los permisos se asignan a roles y los roles a usuarios. |
| **MRR** | Ingreso recurrente mensual. |
| **Punto de extensión** | Conexión prevista por el núcleo para que un paquete agregue comportamiento sin modificarlo. |
| **Caso A / B / C / D** | Tipos de solicitud de un negocio adicional según lo que ya exista en la fábrica. |
| **SaaS** | Software que se usa por internet y se paga como servicio. |
