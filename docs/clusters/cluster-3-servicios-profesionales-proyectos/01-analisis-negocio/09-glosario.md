# 09. Glosario

| Término | Definición |
|---------|------------|
| **Adicional (Change Order)** | Trabajo no presupuestado que aprueba el cliente. |
| **Avance físico** | Porcentaje realmente ejecutado de una partida. |
| **Certificación de avance** | Documento que valoriza lo ejecutado para cobrarlo. |
| **Destajo** | Trabajo pagado por cantidad ejecutada. |
| **Fee de agencia** | Honorario propio, separado de la pauta. |
| **Fondo de reparo** | Porcentaje retenido como garantía de los trabajos. |
| **Gasto suplido** | Pago hecho a nombre del cliente que luego se reembolsa. |
| **Iguala (Retainer)** | Honorario fijo mensual por un servicio continuo. |
| **Línea base** | Primer presupuesto aprobado, usado como comparación. |
| **Pauta publicitaria (Ad Spend)** | Dinero invertido en anuncios de Meta, Google, etc. |
| **Partida** | Rubro de trabajo con unidad, metrado y precio unitario. |
| **Terna** | Grupo final de candidatos presentados al cliente. |
| **Costo hora** | Costo de una hora de trabajo de una persona. |
