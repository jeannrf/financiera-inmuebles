# 09. Glosario

| Término | Definición |
|---------|------------|
| **Antigüedad de saldos** | Clasificación de deudas por días de atraso. |
| **CMV / COGS** | Costo de la Mercadería Vendida. |
| **Comanda** | Pedido de una mesa que llega a cocina. |
| **Costo promedio** | Costo unitario ponderado de las compras en stock. |
| **Kardex** | Registro cronológico de entradas y salidas de un producto. |
| **Línea de crédito** | Máximo que un cliente puede deber. |
| **Lote** | Grupo de productos con la misma fecha de vencimiento u origen. |
| **Make-to-Order** | Fabricar solo cuando hay un pedido confirmado. |
| **Merma** | Pérdida de mercadería por deterioro o desperdicio. |
| **Nota de crédito** | Comprobante que anula o reduce una venta. |
| **Orden de producción** | Instrucción de fabricar un pedido. |
| **PEPS** | Primeras Entradas, Primeras Salidas. |
| **Picking** | Preparación física de un pedido en almacén. |
| **POS** | Punto de venta. |
| **Preventista** | Vendedor que toma pedidos en ruta para entrega posterior. |
| **Receta** | Insumos y cantidades de un plato. |
| **Seña** | Anticipo para confirmar un pedido. |
| **SKU** | Código único de un producto. |
| **Stock mínimo** | Cantidad que dispara la reposición. |
