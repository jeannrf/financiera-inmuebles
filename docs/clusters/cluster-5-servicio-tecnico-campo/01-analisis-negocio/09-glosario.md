# 09. Glosario

| Término | Definición |
|---------|------------|
| **Abono** | Contrato con pago periódico por un servicio recurrente. |
| **Bahía** | Puesto de trabajo de un taller. |
| **Cuadrilla** | Equipo de personal que trabaja en campo. |
| **Deducible** | Parte de un siniestro que paga el asegurado. |
| **Field Service** | Servicio técnico en las instalaciones del cliente. |
| **IMEI** | Número de identificación de un celular. |
| **Orden de Trabajo (OT)** | Documento que controla un servicio de principio a fin. |
| **SN** | Número de serie. |
| **Tarifa de diagnóstico** | Cobro por revisar un equipo. |
