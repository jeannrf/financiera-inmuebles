# 09. Glosario

Términos del rubro. Los de la plataforma están en el [glosario general](../../../general/01-analisis-negocio/09-glosario.md).

| Término | Definición |
|---------|------------|
| **Alquiler / Arrendamiento** | Cesión del uso de un departamento a cambio de un pago mensual. |
| **Alícuota** | Porcentaje de participación de una unidad en los gastos comunes. |
| **Analista** | Empleado que realiza la operación diaria (cobros, vouchers, lecturas) con acceso restringido. |
| **Arbitrios** | Tributo municipal por limpieza pública, parques y serenazgo, que paga el propietario. |
| **Autovalúo** | Valor del predio declarado cada año, sobre el que se calcula el impuesto predial. |
| **Cap Rate** | Ingreso neto anual dividido entre el valor del activo. |
| **Cochera** | Espacio de estacionamiento que se alquila como una unidad independiente. |
| **Check-in / Check-out** | Devolución y entrega de un bien alquilado, con acta. |
| **Cierre de mes (candado)** | Bloqueo de un período cuando todo está cobrado, verificado y pagado; después ya no se modifica. |
| **Contrato** | Acuerdo entre el inquilino y el dueño sobre un departamento, con fechas, monto y condiciones. |
| **Cuota** | Obligación de pago de un concepto (alquiler, agua, luz…) para un período, con fecha de vencimiento. |
| **DNI** | Documento Nacional de Identidad (8 dígitos). |
| **Dossier de desalojo** | Expediente con lo necesario para iniciar una acción legal contra un inquilino moroso. |
| **Fondo de reserva** | Dinero separado para gastos futuros o extraordinarios del edificio. |
| **Horómetro** | Contador de horas de uso de una máquina. |
| **Impuesto a la renta de primera categoría** | Impuesto sobre los ingresos por alquiler de inmuebles (persona natural). |
| **Impuesto predial** | Impuesto municipal anual sobre el valor de los predios. |
| **Incobrable** | Cuota que se da por perdida; permite el cierre del período. |
| **Incremento programado** | Nuevo monto de alquiler registrado con anticipación que rige desde una fecha futura. |
| **Inquilino / Arrendatario** | Persona que alquila un departamento. |
| **Juicio de desalojo** | Proceso judicial para recuperar un inmueble de un inquilino que no paga; requiere los datos personales y laborales del inquilino. |
| **Lectura anterior / actual** | Valores registrados del medidor en dos fechas; su diferencia es el consumo. |
| **Mantenimiento** | Cuota que cubre los gastos de las áreas comunes (vigilancia, limpieza, ascensor, energía común). |
| **Mejora** | Inversión en el inmueble (pisos, ventanas, remodelación) que aumenta su costo y valor. |
| **Morosidad / Atraso** | Situación de una cuota no pagada después de su vencimiento; se mide en días. |
| **Ocupación** | Porcentaje de unidades alquilables que están alquiladas; la meta del dueño es el 100 %. |
| **Pago parcial** | Abono menor que el monto de la cuota; la cuota queda con saldo pendiente, sin intereses. |
| **Puesto de mercado** | Local o espacio dentro de un mercado que se alquila como unidad. |
| **Suministro** | Conexión con el proveedor (luz o agua) que genera un recibo propio; agrupa a los departamentos que se alimentan de ella. |
| **Período de recuperación** | Años necesarios para recuperar la inversión con el ingreso neto (meta del cliente: 12–15 años). |
| **Período** | Mes y año al que corresponde una cuota, un pago o un voucher (por ejemplo, enero 2026). |
| **Plin / Yape** | Billeteras digitales peruanas para transferencias inmediatas. |
| **Prorrateo** | Reparto de un recibo común entre los departamentos de un mismo suministro, proporcional al consumo de cada uno. |
| **Rendimiento / Rentabilidad** | Porcentaje de ganancia neta respecto a lo invertido, en un período (mensual o anual). |
| **Rol de limpieza** | Cronograma de turnos en que cada departamento limpia las áreas comunes. |
| **Self-storage** | Alquiler de mini-bodegas. |
| **Semáforo / Calificación** | Clasificación verde, amarillo o rojo de un inquilino según su historial de pagos (al estilo Sentinel / Infocorp). |
| **Sentinel / Infocorp** | Centrales de riesgo crediticio en Perú que califican el comportamiento de pago de las personas. |
| **Submedidor** | Medidor interno de cada departamento, dentro del edificio, detrás del medidor general del proveedor. |
| **SUM** | Salón de Usos Múltiples de un edificio. |
| **Suministro** | Número de servicio del proveedor de luz o agua; un edificio puede tener varios. |
| **SUNAT** | Superintendencia Nacional de Aduanas y de Administración Tributaria. |
| **UIT** | Unidad Impositiva Tributaria: valor de referencia que el Estado fija cada año (por ejemplo, S/ 5 350 en 2025). El cliente la usa como índice para actualizar el valor de sus inmuebles. |
| **Vacancia** | Tiempo en que una unidad está sin contrato y no genera ingreso. |
| **Valor actualizado** | Valor del inmueble ajustado por el factor UIT, más las mejoras. |
| **Vigilante (huachimán)** | Personal de seguridad del edificio (3 turnos de 8 h para cubrir 24/7). |
| **Voucher** | Comprobante de pago (captura de Yape o transferencia) que envía el inquilino. |
| **Áreas comunes** | Espacios compartidos del edificio (ascensor, pasillos, ingreso), cuyos gastos se cubren con el mantenimiento. |
