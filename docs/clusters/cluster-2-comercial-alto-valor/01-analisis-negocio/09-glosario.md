# 09. Glosario

| Término | Definición |
|---------|------------|
| **Allotment** | Cupo de plazas bloqueadas con un proveedor para una salida. |
| **Alistamiento** | Preparación de un vehículo antes de venderlo (chapa, pintura, trámites). |
| **Aseguradora** | Empresa que asume el riesgo y paga comisión al corredor. |
| **Bróker / Corredor de seguros** | Intermediario entre el cliente y la aseguradora. *No confundir con el bróker de bolsa.* |
| **Consignación** | Vender un bien ajeno y liquidarle al dueño. |
| **Cotización versionada** | Propuesta que conserva todas sus versiones. |
| **DMC** | Destination Management Company: operador local de destino. |
| **Forecast** | Proyección de ingresos según la probabilidad de cierre. |
| **Hito de cobro** | Parte del precio que se cobra al cumplirse una condición. |
| **Lead** | Contacto interesado aún no calificado. |
| **Pipeline** | Etapas por las que pasa una oportunidad. |
| **Póliza** | Contrato de seguro. |
| **Prima** | Lo que paga el asegurado por la cobertura. |
| **Ramo** | Tipo de seguro: Vida, Autos, Salud, Patrimoniales. |
| **Retoma (Trade-in)** | Recibir un vehículo usado como parte de pago. |
| **Siniestro** | Evento cubierto por el seguro que origina un reclamo. |
| **Sub-agente** | Vendedor externo con comisión cedida. |
| **Voucher (viajes)** | Confirmación de reserva con un proveedor. *En C1, "voucher" es un comprobante de pago: se resuelve con etiquetas por vertical.* |
