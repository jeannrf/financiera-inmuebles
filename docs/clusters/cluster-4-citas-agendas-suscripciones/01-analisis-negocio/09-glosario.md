# 09. Glosario

| Término | Definición |
|---------|------------|
| **Bono / Paquete** | Grupo de sesiones pagadas por adelantado. |
| **Churn** | Porcentaje de clientes que se dan de baja en un período. |
| **Congelamiento** | Pausa de una membresía, que extiende su vigencia. |
| **Consentimiento informado** | Autorización del paciente para un tratamiento. |
| **Cupo** | Máximo de personas en un grupo o clase. |
| **Grooming** | Baño y peluquería de mascotas. |
| **Historia clínica** | Registro evolutivo de la atención de un paciente. |
| **Ingreso diferido** | Dinero cobrado por un servicio aún no prestado. |
| **Matrícula** | Inscripción de un alumno en un curso o ciclo. |
| **MRR** | Ingreso recurrente mensual. |
| **No-show / Inasistencia** | Persona que no llega a su cita sin avisar. |
| **Odontograma** | Esquema dental del paciente. |
| **Pensión** | Pago periódico de un alumno. |
| **Turnero** | Sistema de asignación de turnos. |
