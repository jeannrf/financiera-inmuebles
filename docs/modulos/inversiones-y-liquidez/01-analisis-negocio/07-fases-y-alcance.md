# 07. Fases y alcance

**Etapa 2:** cuentas, plazos fijos (con alerta de vencimiento), operaciones de BVL, dividendos, rendimientos y **reporte tributario anual**.

**Etapa 3 o después:** importar Excel o CSV de movimientos.

**Fuera de alcance:**

- Conexión automática con bancos o brókers (no suele haber API pública). El registro es **manual** en las etapas 1 y 2.
- Precios de acciones en tiempo real: se valoriza con el último precio ingresado.
- Declaración tributaria automática ante SUNAT.
- Recomendar inversiones: el sistema ordena e informa; la decisión es del dueño.
