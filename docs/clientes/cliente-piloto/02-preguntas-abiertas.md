# 02. Preguntas abiertas: cliente piloto

> Hay que enviárselas por escrito (el cliente dijo: "pásame las preguntas por escrito").
> Las marcadas con ⭐ conviene resolverlas primero.


| ID | Pregunta |
|----|----------|
| CLI-Q-01 | ¿Confirmamos la fecha y la hora de la próxima reunión (unos 28 de noviembre de 2026) y el coworking? |
| CLI-Q-02 ⭐ | ¿Nos puede compartir los **Excel actuales** (alquileres y servicios) y ejemplos de vouchers y recibos, aunque sea con datos ocultos? |
| CLI-Q-03 ⭐ | **Propiedad intelectual (ya no es pregunta):** el equipo decidió la opción (A). Hay que **comunicarle** que el producto será de una empresa del equipo y que usted es el primer cliente, y confirmar que está de acuerdo. |
| CLI-Q-04 ⭐ | ¿Le parece bien una **aplicación web** (se usa desde el navegador de la laptop y del celular) en lugar de un programa instalado en una sola computadora? |
| CLI-Q-05 | ¿Qué nombre le gustaría para el software? |
| CLI-Q-06 | ¿Cuántos inmuebles, departamentos e inquilinos tiene hoy, y cuántos espera tener en 2–3 años? |
| CLI-Q-07 | ¿Cuántos analistas trabajarían al inicio? ¿Ya hay alguno? |
| CLI-Q-08 ⭐ | ¿Cuál será su **tercer negocio**? Mencionó presupuestos de construcción. ¿Sigue siendo la idea? |
| CLI-Q-09 ⭐ | Si la plataforma se ofrece también a otras empresas, ¿cómo le gustaría participar: primer cliente con condiciones especiales, socio, otra fórmula? |

## Actualización de estas preguntas tras el giro a SaaS

- **CLI-Q-03 ya tiene decisión interna:** una empresa propia del equipo ([NUC-Q-09](../../general/01-analisis-negocio/08-preguntas-abiertas.md#decisiones-tomadas)). El cliente dijo
  que "igual van a ganar" con cualquiera de las dos opciones, pero aún no conoce el modelo SaaS. Hay que **explicárselo en la reunión, antes de hablar de precio**.
- **CLI-Q-04 deja de ser una pregunta:** un SaaS es una aplicación web. Hay que informárselo con la ventaja que le da: acceso desde cualquier laptop o celular.
